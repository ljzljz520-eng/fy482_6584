# 医疗陪诊客户管理

这是一个使用 Go 1.22 和本地 CSV 表格持久化的陪诊客户管理项目。网页提供客户新增与修改、城市和患者关系筛选、客户详情、回访时间与备注维护、CSV 客户表导入，以及导入前的重复手机号预览。

## 运行入口

从项目根目录启动后端：

```bash
go run ./cmd/escortcrm -addr :8080 -data ./data
```

浏览器访问 `http://localhost:8080`。运行时会在 `data/` 下创建 `customers.csv`、`operations.csv` 和 `imports.csv`，这些文件可直接使用常见表格软件打开。

## 前端构建

需要 Node.js 20：

```bash
cd web
npm install
npm run build
```

构建产物位于 `web/dist/`，后端运行时直接使用内嵌的 `web/src/`，因此开发启动不依赖预先构建前端。

## 业务链路测试

所有 Go 测试均从模块根目录运行：

```bash
go test -count=1 ./...
```

当前练习版本保留了一个可稳定复现的导入缺陷：同一导入编号连续提交两次同一客户表后，客户表和操作日志都会出现重复记录。因此重复提交场景的业务测试预期会失败，其余链路应通过。

## 客户表格式

网页导入接受带表头的 CSV 文件。支持的表头为 `name`、`phone`、`relationship`、`city`、`followUpAt`、`notes`，也兼容对应中文表头 `姓名`、`手机号`、`患者关系`、`服务城市`、`回访时间`、`备注`。回访时间使用 RFC3339 格式，例如 `2026-08-20T09:30:00+08:00`。
